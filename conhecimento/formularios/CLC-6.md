# PROJETO BÁSICO

**Este formulário NÃO possui modelo padronizado — é intencionalmente em branco.**

Motivo: pela complexidade e variação técnica dos documentos de engenharia, não há um formulário-padrão a seguir. O Projeto Básico é elaborado caso a caso, conforme a natureza da obra/serviço de engenharia.

## Orientação ao assistente
- Quando o enquadramento admitir "Termo de Referência **ou** Projeto Básico" (grupo_alternativa TR_ou_PB) e o objeto for **obra ou serviço de engenharia**, o caminho é o Projeto Básico — mas não há template a preencher.
- O Projeto Básico deve contemplar os elementos mínimos do **art. 6º, inciso XXV, da Lei 14.133/2021** (art. 22 da Portaria): elementos necessários e suficientes para definir e dimensionar a obra/serviço, com base no ETP, assegurando viabilidade técnica, tratamento do impacto ambiental, avaliação do custo e definição dos métodos e prazo de execução.
- O assistente deve orientar o usuário a elaborar o documento conforme esses elementos legais, sem impor uma estrutura de formulário que não existe.
